# HH_to_Postgres

## Описание
    Парсер получает данные о компаниях и вакансиях с сайта hh.ru, 
    и загружает полученные данные в созданные таблицы.
## Установка
- [клонируйте репозиторий](https://github.com/AlexJharinov/HH_to_Postgres)

## Запуск программы
    Точка входа в программу осуществляется из корня пректа 
    файла main
